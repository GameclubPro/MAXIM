# Реализация визуального направления Major и Публика

Дата: 28 сентября 2026. Основание: [план редизайна](miniapp-redesign-plan.md).
Область: `apps/miniapp`, визуальные сценарии и документация. API, контракты,
миграции и закрытый Safety Desk не изменяются.

## Принятые решения

Выбран «Сигнал»: графитовая фирменная полоса, лаймовый знак «М», кобальтовые
команды, более контрастная типографика и разделённые действия в строках сообществ.
«Редакция» доступна только в preview через `?preview=1&design=editorial`.
Сравнение сделано на одинаковых данных: типографическая альтернатива компактна,
но графитовая полоса лучше выделяет продукт, сохраняя первый чат выше 150px
внутри WebView шириной 320px. Это авторский выбор, не результат исследования аудитории.

По уточнению пользователя Публик получил оранжевую идентичность: знак `#FF8A38`,
контрастный акцент `#B54708` в светлой теме и `#FFAD70` в тёмной. Цвет успеха
сохраняет самостоятельный смысл. Удалено старое зелёное переопределение экрана постов.

конфликт стоп-слов и переходы между разделами.

## Корректировки плана

- Оформление главной вынесено в ленивый `chats-page-signal.css`, чтобы прямой вход
  в комментарии не загружал стили каталога. Общая презентация Major остаётся
  в профильном `workspace`-слое.
- Новые растровые иллюстрации не включены: генерация изображений недоступна в
  текущей сессии. Используются реальные аватары/медиа и существующие материалы
  подключения. Отдельный набор иллюстраций остаётся открытым пунктом.
- Не переписаны уже работающие редакторы и механизмы отправки. Новая система
  применена к их общим компонентам, а сценарии проверены на сохранение поведения.
- Исправлены две неточности автоматического визуального набора: проверка спама
  открывает журнал, а проверка клавиатуры Публика сначала закрывает выбор получателей.
  Проверки доступности и контраста не ослаблены.

## Ресурсы и загрузка

Manrope 4.504: исходный TTF 165420 байт, WOFF2 53732 байта, уменьшение на 67.5%.
Проверено совпадение 742 глифов, карты 678 символов, диапазона веса 200–800
и лицензионных метаданных. Кириллица сохранена. Исходный TTF остаётся в репозитории;
браузер загружает только WOFF2, предусмотрен системный fallback и `font-display: swap`.
Лицензия SIL OFL 1.1 поставляется в `/app/licenses/manrope.txt`.

Новых изображений, библиотек и сетевых сервисов нет. Лимиты сборки не повышены.

  нижние системные отступы и клавиатура на 320/390/393/1280px в обеих темах.
- `signal-design.browser.mjs`: новый путь через сохранение и повтор после ошибки,

## Выпуск и открытая приёмка

28 сентября 2026 выпущен только `miniapp-major-static` штатным wrapper.
Исходный коммит приложения: `8757eb673c34aae9cf5b1f8d9213cf74a662e0c2`.
Манифест выпуска: `release-20260928T003637Z-8757eb673c34`.

До выпуска успешно завершились [Required](https://github.com/GameclubPro/MAXIM/actions/runs/36361245757)
и [Analyze JavaScript and TypeScript](https://github.com/GameclubPro/MAXIM/actions/runs/36361245734)
для этого точного SHA. Первый прогон CI остановился на серверном тесте
`WebhookRateLimitService`, который использует реальное время и может пересечь
границу секунды между запросами. Повторный прогон того же коммита прошёл;
код API и проверки не менялись, обходов release-gate не применялось.
Для отдельной стабилизации CI следует зафиксировать часы в этом тесте.

Использован проверенный неизменяемый образ из GitHub CI через `preload-ci-image`:
контрольная сумма, метки образа и свободное место проверены штатной процедурой.
Сборка на VPS не запускалась. API, Postgres и Redis не пересоздавались.

После выпуска проверены `https://major-maksimov.ru/app/`, публичный API live
и локальные API live/ready. Дополнительная browser-проверка опубликованной сборки
на 393px прошла для главной Major, каталога Публика и публикаций в обеих темах:
нет горизонтального переполнения, ошибок JavaScript или загрузки ресурсов,
оранжевые цвета соответствуют теме. Использованы демонстрационные данные;
запросы к рабочим данным блокировались, служебная телеметрия перехватывалась локально.
Проверены точные байты WOFF2 и доступность лицензии шрифта.
Последующие коммиты этого отчёта не меняют указанный SHA выпущенного приложения.

Открыты: проверка настоящего MAX на Android/iPhone (клавиатура, системный Back,
выбор файлов, медленная сеть), контролируемое сравнение времени загрузки,
отдельные иллюстрации и пользовательская оценка визуального направления.
