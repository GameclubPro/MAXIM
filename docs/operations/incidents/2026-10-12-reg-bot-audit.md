## Исправления

1. Ночной планировщик учитывал ACTIVE/admin membership, но не сохранённый запрет
   повторной активации и потолок `send_message`. В очереди подтверждены повторные
   ошибки `MAX action capability requires explicit activation`. Допуск планировщика
   и аудит теперь учитывают эти факты вместе с финальным исполнителем. Неизвестные
   старые permissions остаются доступными для защищённого refresh; независимый
   подходящий бот может продолжать работу. Квитанции и границы текущих сессий сохранены.
   Целевые 18 наборов / 639 проверок, включая native stores, прошли.
2. `postgres-audit commercial-quality` превышал неизменный `temp_file_limit=8MB`:
   несколько материализованных CTE хранили исходный JSON. Теперь до материализации
   извлекаются только ограниченные скалярные поля. Сохранены индекс, один проход
   до 5 001 строки, sentinel, права и семантика отчёта. Native-регрессия с большой
   metadata воспроизводила отказ до исправления и прошла после; все 8 проверок успешны.

Отключение антидубля выполняется штатным `off --expected-revision <актуальная>`
через preview/apply. Оно отзывает новые действия, сохраняя квитанции и уже начатые
неопределённые эффекты. Откат API возможен только на совместимый immutable release.
