# Удобство публикаций в Публике

Аудит от 29 сентября 2026 года. Область: кабинет Публика, создание поста,
получатели, редактор, вложения, расписание, дополнительные действия и проверка
перед отправкой. Изменения относятся к mini app; серверный протокол публикации
и модель черновиков сохраняются.

## Найденные проблемы и реализованный план

| Приоритет | Проблема                                                                                | Решение                                                                                                  |
| --------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| P1        | Основная кнопка уходит под длинный текст и все настройки                                | Отдельная нижняя строка редактора; прокручивается только содержимое                                      |
| P1        | При открытии клавиатуры основная кнопка полностью исчезает                              | Кнопка остаётся в доступной области visualViewport, без перекрытия текста                                |
| P1        | Форматирование и вложения расположены после текста; длинный пост требует прокрутки вниз | Подписанная панель над текстом, закрепляющаяся при прокрутке редактора                                   |
| P1        | Выбор получателей автоматически фокусирует поиск и вызывает клавиатуру                  | Начальный фокус на диалоге; поиск включается по нажатию                                                  |
| P1        | Выбранные получатели вместе с клавиатурой вытесняют список и кнопку завершения          | Компактные отступы при клавиатуре; выбор остаётся виден в счётчике и строках, лента выбранных скрывается |
| P2        | Завершение выбора получателей обозначено только галочкой в верхнем углу                 | Нижняя кнопка «Готово» с количеством выбранных получателей и отдельное закрытие                          |
| P2        | «Опубликовать» в редакторе фактически только открывает проверку                         | «Проверить пост» в редакторе; окончательное действие остаётся в проверке                                 |
| P2        | Закрепление и автоудаление занимают место в каждом обычном посте                        | Сворачиваемый блок с видимым описанием активных настроек                                                 |
| P2        | «Один раз» не объясняет, что это отложенная отправка                                    | «Отложить» рядом с «Сейчас» и «Расписание»                                                               |
| P2        | Удаление фото и выбор получателя предпросмотра меньше удобной зоны касания              | Размер интерактивных элементов не менее 44 px                                                            |
| P2        | На узком экране кнопка создания превращается в неподписанный плюс                       | Подпись «Создать» сохраняется                                                                            |
| P2        | Выбор способа создания не объясняет разницу, акцентирует пересылку                      | Основной акцент на написании; пояснения для текста/медиа и переноса из MAX                               |
| P2        | На компьютере редактор растягивается на весь экран                                      | Ограничение ширины рабочей области до 800 px                                                             |

Порядок реализации: доступность основного действия → редактор и вложения →
получатели и необязательные настройки → понятные подписи → регрессионная
проверка → выпуск только `miniapp-major-static` через штатный deploy wrapper.

## Проверка

Локальные сценарии используют preview transport и MAX Bridge shim. Реальные
сообщения пользователям не отправляются.

- `node scripts/agent/preflight.mjs`
- `npm run check:miniapp`
- `npm run build:miniapp:production`
- `node apps/miniapp/test/publication-composer-usability.browser.mjs`
- `node apps/miniapp/test/publication-time-picker.browser.mjs`
- `node apps/miniapp/test/publication-video-picker.browser.mjs`
- Локальные screenshot-сценарии редактора, большого списка получателей,
  недоступного получателя, расписания, кнопок, дополнительных действий и проверки.

Новый браузерный сценарий проверяет полный путь «Создать → Написать → выбрать
получателей → вставить длинный текст → настроить действия → проверить → вернуться
к редактированию → подтвердить». Проверяются сохранность текста, доступность
основной кнопки и панели инструментов, поиск получателей при открытой клавиатуре,
подтверждение выбранных действий и отсутствие ошибок JavaScript. Матрица:
iPhone SE, iPhone 15, Pixel 7 и desktop, светлая и тёмная темы.

Браузерная эмуляция не заменяет приёмку на физических устройствах внутри MAX.
После выпуска для неё нужны реальные iOS/Android WebView: нативный выбор файлов,
клавиатура, BackButton и возврат из MAX. Утверждать отсутствие любых дефектов вне
проверенных сценариев по этому аудиту нельзя.
